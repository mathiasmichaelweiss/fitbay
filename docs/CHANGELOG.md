- «Уточнить порцию»: посуда (4 типа), «Не знаю, считай обычную порцию», размер, заполненность, вес.
- Расчёт через `POST /ai/food_photo|food_text`; если фото не прошло, пересчёт по описанию с сообщением прототипа.
- Редактор результата (renderREdit): вся порция с кнопками ½ ¾ ×1¼ ×1½, состав с правкой граммов и удалением, «Добавить: 1 ст. л. масла» через ИИ (`food_items`), название на выбор, КБЖУ вручную.
- Сохранение как в прототипе: поправка веса в общую базу, если вес отличается от оценки ИИ больше чем на 15% (не для блюд из книги и не при правке); «Сохранить в мои блюда»; счётчик использования рецепта.
- Редактирование: нажать на блюдо в «Съедено», заголовок «Изменить блюдо», выбор приёма пищи (Авто, Завтрак, …).

- «Рассказать про день»: разбор ИИ, галочки, имя и приём пищи у каждого блюда, время по слоту (SLOT_H), блюда из книги подтягиваются.
- Новые ИИ-задачи на сервере с промптами прототипа: `food_items`, `food_portion`, `food_mod`. Заглушка ИИ отвечает на все задачи для e2e.

## 2026-10-12 · A2.5 ИИ-прокси (каркас и основные промпты)
- `POST /ai/{task}`: промпт собирается на сервере из данных пользователя (профиль, еда, тренировки, рецепты, поправки), ключ только на сервере.
- Перенесены дословно из прототипа: оценка еды по фото и тексту (с посудой, масштабом, плотностями, подсказками общей базы и личных взвешиваний), рассказ за день, коуч. Остальные задачи отвечают 501 до переноса их экранов.
- Провайдер OpenAI (Chat Completions, JSON-режим, фото), модель по умолчанию `gpt-5.6-luna`, меняется для каждой задачи записью `CONFIG / AI` без релиза. `AI_MOCK=1` для разработки без ключа, без ключа 503 «ИИ недоступен в этом окне.»
- Лимиты из прототипа (trial, full) и мягкие сообщения `AIMSG` без слова «лимит», Unlimited 100 в день. Счётчик `USAGE#<дата>` с TTL, токены по задачам в счётчике и в логе (без персональных данных).
- Коуч не вызывается повторно, пока не изменилась еда за день (`mealsKey` прототипа); ответ без длинного тире.
- Если фото не прошло, пересчёт по описанию и весу, как в прототипе.
- `groupMeals`, `mealsKey` перенесены в `@fitbay/calc` (нужны серверу для коуча). Инструкция по локальному запуску: `docs/LOCAL.md`.

## 2026-10-12 · A2.6 Общая база поправок веса
