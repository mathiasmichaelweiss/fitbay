# FitBay: правила для агента

Спека: `docs/SPEC.md`, задачи: `docs/TODO.md`, журнал: `docs/CHANGELOG.md` (новая запись сверху на каждый пакет).

## Прототип = источник правды по поведению и виду (обязательно)
- Прототип лежит в `docs/prototype/kalorii.html` (артефакт FitBay, версия 138). **Перед каждой задачей найти в нём соответствующий код** (функции, тексты, цвета, проверки) и переносить его, а не придумывать своё.
- Тексты берутся дословно из прототипа. i18n: ключ = русский текст (как `T("...")` в прототипе), немецкий из словаря прототипа `src/i18n/proto-de.json`; чего там нет, в `extra-de.ts`.
- Все числа только из `@fitbay/calc` (порт `CALC`). Эталоны `packages/calc/src/golden.json` сняты запуском настоящего CALC прототипа; новые формулы добавлять так же: сначала эталон из прототипа, потом порт.
- Если спека расходится с прототипом, прототип задаёт поведение, спека задаёт архитектуру (спека, раздел «Источник правды»). Навигация из 4 разделов внизу (спека, раздел 6) это осознанная перепаковка UX.

## UI (обязательно)
- Основа всех компонентов: **shadcn/ui** в `apps/web/src/components/ui` (стиль new-york, Tailwind v4, Radix), стилизованные под прототип: палитра `:root` прототипа в `src/tokens.css`, плитки `Tile` (цвета t-orange, t-cream, t-yellow, t-teal, t-peach, t-green, t-dark), `.primary` кнопка, `.seg` сегменты, круги `CapsRings` (порт capsSvg).
- **Никаких нативных оверлеев и контролов**: нет `<select>`, `<input type="date|time|month">`, `<datalist>`, `alert/confirm/prompt`. Вместо них `Select`, `DatePicker` (шторка + `Calendar`), `Dialog`, `Drawer`, `Popover`. E2E `e2e/native.spec.ts` это проверяет.
- На мобильном основной оверлей: `Drawer` (снизу). Поля 16 px, тач-цели от 44 px, без горизонтального скролла на 360 px.
- Все строки через i18n (`ru`, `de`), ключи в обоих словарях (юнит-тест сверяет).
- Каждый новый компонент добавляем в витрину `/ui` (`src/Showcase.tsx`).

## Код
- Все производные числа (норма, расход, БЖУ) только из `@fitbay/calc`. Экраны только отображают.
- Данные фронта через `src/data/api.ts` (local или http) и хуки TanStack Query.
